# Live site source

rohinmanvi.com is served from the `gh-pages` branch, which holds these files plus `CNAME`, `.nojekyll` and `assets/pdf/Rohin_Manvi_CV_2.pdf`.

To update: edit here, copy the files into a `gh-pages` checkout, commit and push.

The al-folio Jekyll source in the rest of this repo is no longer deployed. Its deploy workflow is disabled (`.github/workflows/deploy.yml.disabled`) so it can't overwrite `gh-pages`.
